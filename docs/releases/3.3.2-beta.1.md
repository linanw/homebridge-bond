# Bond metadata sync beta

Based on aarons22/homebridge-bond 3.3.0 and the linanw Matter endpoint implementation at ec2c038. This release uses the public npm name `@linanw/homebridge-bond` and the `beta` dist-tag. The MatterDesk editor requires the revision-one MatterDeskPluginMetadata cluster on the controller and a compatible client. The iPhone companion is built from the companion directory in this tag.

The Linux and DSM integration tests exercise a scoped install over an existing Homebridge 2.4.0 Bond accessory cache. The live fixture uses two BD-1000 bridges running v4.34.1. MatterDesk issued a rename and a room-only move, and a separate read from the physical Bond bridge confirmed each change. A combined edit restored the original values. Appliance power and other controls were left untouched. The nine physical devices retain ten Matter controls, with metadata attached to the primary control for each device.

Without a bound HomeKit companion, MatterDesk displayed Apple delivery failure while independently confirming Bond. Automated tests cover request replay, stale versions, unconfirmed Apple requests, and partial HomeKit readback. The iOS app built for physical iPhone hardware with Xcode. Successful Apple Home write and readback on a real home are pending validation. Setup and rollback are described in the repository README.
