# Bond Matter 3.3.2-beta.2

The fan cluster checks the originating Matter actor before invoking the Bond control handler. Bond Push UDP updates still publish mode and speed, including the initial read after Homebridge restores its cache. The bridge carries each existing accessory's Matter UniqueID across endpoint reconstruction.

The package uses the existing platform, accessory UUIDs, endpoint numbering and metadata storage. Keep the current Homebridge data directory and child-bridge configuration when upgrading. A return to 3.3.2-beta.1 can reproduce the fan feedback loop.

Verified with Homebridge 2.4.0 on Linux and a six-speed Bond ceiling fan on the Synology NAS. The original MatterDesk node and endpoint remained usable. Off, low speed, 50 percent and the original 100 percent setting all matched the Bond and Matter readbacks. Local publication and overlapping remote control are covered by the regression test.
